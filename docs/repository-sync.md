# 仓库同步与接续

正式仓库：https://github.com/an5763419-cloud/ai-desktop-girlfriend。
仓库保持私有。当前开发分支：codex/feat/airi-m0。
main 保留用户创建的初始记录，并提供完整源码与进度入口。完整开发成果从当前开发分支读取。
upstream 指向 moeru-ai/airi，只用于调查和取回已确定的上游提交。

## 每次开始

1. 检查当前目录、分支和 git status。
2. 若有未提交修改，先保留并核对来源。
3. 读取 docs/status.md、docs/decisions.md 和最近提交。
4. 获取 origin 更新，检查本地与远端差异后再接续。
5. 切换电脑端或云端前，提交已完成工作并推送同一开发分支。

不强制推送，不覆盖另一端未提交文件，不同时修改同一模块。
首次同步保留远端初始提交，将其合入开发分支。
初始 README 的仓库标题与本项目说明合并，上游 README 保留。

## Windows 接续约定

项目位于 E:\ai\ai桌面女友。当前尚未连接用户 Windows，不能宣称目录已经创建。
首次克隆时选择 codex/feat/airi-m0。main 的 README 提供该分支入口。
同步代码不等于安装完成。本地依赖、模型权重和工具缓存不作为源码上传。
模型版本、资源来源、许可和复现命令保存在验证文档中。

## 首次同步范围

保存固定 AIRI 基线、项目修改、制作脚本、验证截图和进度记录。
不上传云端 node_modules、模型缓存或临时 Blender 扩展副本。
开发分支推送完成后检查远端 SHA，并从 GitHub 读取进度文件确认内容。
上游发布流程保留在源码中，本次不触发 Windows 发布或创建 Release。
