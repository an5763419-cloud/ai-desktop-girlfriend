## 复现环境

- Node 26.7.0，pnpm 11.24.0，Electron 43.4.1。
- 工作目录 /workspace/airi，依赖缓存 /workspace/.pnpm-store。
- pnpm install --frozen-lockfile --store-dir /workspace/.pnpm-store --reporter=append-only。
- pnpm -F @proj-airi/stage-web dev --host 127.0.0.1 --port 5173。
- Electron 使用 Xvfb :99 和专用 APP_USER_DATA_PATH=/workspace/airi-test-profile。
- pnpm -F @proj-airi/stage-tamagotchi dev -- --no-sandbox --enable-unsafe-swiftshader。
- 容器内无可用 Chromium SUID 沙箱，因此验证进程使用 --no-sandbox。该参数不进入 Windows 产品配置。
- APP_REMOTE_DEBUG=true，APP_REMOTE_DEBUG_PORT=9250。仅用于本地验收工具连接。
- 原版 Electron 在云端出现 Vulkan/GPU 初始化失败和 DBus 错误。
- agent-browser 0.41.0 经 CDP 读取界面。真实截图来自本地启动的 stage-web。

## Electron 补充验证

重启时增加 --disable-features=Vulkan，使用软件图形路径。
截图 m0-electron-stage.png 显示上游二维示例角色，m0-electron-settings.png 显示原版设置。
这不是写实 3D 或 Q版外观验收，云端图形日志仍有 DBus、GPU 和证书错误。
截图前必须验证 CDP 当前页面 URL，连接指定 WebSocket 后仍可能选中 inlay。

通过首次引导选择 OpenAI Compatible，地址 http://127.0.0.1:8081/v1/。
引导强制要求密钥，填入无效占位值 local-unused。没有使用付费服务或真实密钥。
连接检测调用本地模型成功，模型列表可见并保存。
通过主窗口 Open Chat 打开聊天窗，发送中文消息。
服务明确返回 10891 token 超过 4096 上下文，UI 显示错误和 Retry。
已将本地测试上下文改为 16384，通过 Retry 重试。超过八分钟未产出回复，人工停止服务。
日志在提示处理 267.28 秒时记录 2048 token，速度 7.66 token/s。
此时软件角色渲染与模型竞争云端两核 CPU。该结果不能代表 RTX 4060 Ti。
应用端到端聊天门槛未通过，下一次先分析提示组成和设置，再进行 GPU 联调。
设置窗口通过主窗口菜单打开。模型子页导航另用 settings 窗口的 hash，属于诊断操作。
