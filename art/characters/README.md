# 角色资产制作

这里管理角色美术源文件、制作配置和导出约定。聊天与记忆仍使用原有应用核心。
当前没有通过用户验收的最终模型。上游 AvatarSample_A/B 仅供加载测试。

## 用户已确认

- 正常比例版：明确成年、成熟优雅、自然真人感。延续美观和优先性感的方向。
- 桌面版：同一身份的真正 3D Q版，保留发型、配色和面部识别特征。
- 脸型、发型、衣装、肤色和声音尚未选定。先给候选预览，再进行正式制作。
- 性感风格用于成年正常比例版本。Q版不沿用身体比例或性感表现。

## 边界

美术目录保存 Blender 源文件、素材来源、导出配方和骨骼映射。
运行时只加载导出资产与声明式配置，不需要安装 Blender 或 MPFB。
角色身份由 characterId 指定，正常版和 Q版各自使用 appearanceId。
更换外观不新建身份，不清空会话或关系记忆。
继续复用 AIRI 的 VRM 渲染、表情与动画能力，不复制一套聊天或渲染逻辑。

拟定每个已确认角色的交付内容：

| 内容 | 责任 |
| --- | --- |
| source/ | Blender 文件、制作配置、材质烘焙设置 |
| licenses/ | 每项皮肤、头发、衣装、动作的来源和许可 |
| exports/normal/ | 成年正常比例模型、材质与预览 |
| exports/chibi/ | 同角色 Q版模型、材质与预览 |
| mappings/ | 骨骼、嘴型、表情、动画语义和已确认点击区域 |

这些是制作约定，尚未实现内容包导入器。不提前写入未实现的 manifest 字段。
大文件版本管理方案在正式模型产出前确定，不将依赖缓存或下载的工具放进 Git。

## 已复用与验证

MPFB 2.0.18 是 Blender 人物生成工具，代码 GPL-3.0-or-later，随附资产 CC0-1.0。
外部下载的素材单独审查，不套用随附资产的 CC0 结论。
VRM Add-on 4.10.3 是导出候选，许可 MIT 或 GPL-3.0-or-later，尚未验证导出。
Blender 4.3.2 已在云端启动。当前没有连接用户 Windows Blender。

制作探针使用 scripts/character-authoring/probe-mpfb.py，复用 MPFB 的 HumanService。
它生成中性技术底模和现成游戏骨架，只验证制作工具，不是女友外观草稿或审美候选。
正式制作先看候选预览，再检查 AIRI 中的皮肤、眼睛、头发、说话和表情。
Blender 画面和程序画面分开标记，不用 Blender 渲染代替程序验收。
